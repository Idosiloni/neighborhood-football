# Languages: Hebrew and English

Every text a user sees comes from `src/i18n` (`t('area.key', vars)`). Nothing in Hebrew or English is
written straight into a screen. The languages: `he` (right to left), `en-US`, `en-GB`.

## How to use it

```js
import { t, tx, tl, dayName, formatKickoff, shortDate, listOf, compareNames } from '../i18n'

t('home.title')                                   // a text
t('home.coming', { name: player.name })           // 'מגיע/ה: {name}' style placeholders
t('sport.goals', { count: 3 })                    // plural: { one, two, other } picked by count
tx('match.goalBy', { name: <b>{p.name}</b> })     // a placeholder that is a React element
tl('stats.taglines.att')                          // a list of texts
```

- Texts live in one file per area, with the **same keys** in `he/<area>.js` and `en/<area>.js`.
  `en` is American English. `en-GB/<area>.js` lists only what is different in British English,
  as full keys: `{ 'sport.name': 'Football' }`.
- Areas: `common` (shared words: loading, save, errors, days, team names), `sport` (positions, goal,
  assist), `match`, `stats`, `onboarding`, `home`, `admin`.
- Plurals: `{ one: 'גול אחד', two: 'שני גולים', other: '{count} גולים' }`. English has no `two`.
  `zero` is optional.
- Code that runs at import time must not call `t()` (the language can change while the app runs).
  Call it inside the component or function. For constant tables, use getters or functions.
- Components re-render on a language change because `App` remounts everything (`key={locale}`).
- Dates and times: `dayName(i)` (0 = Sunday), `formatKickoff('9:30')` (9:30 AM in the US),
  `shortDate(month, day)` (7.11 / 11/7 / 7/11). Sorting names: `compareNames`.
- The database still sends English error keys (`'name taken'`). Map them to texts in the screen.

## Hebrew is gender-neutral

Groups are men, women, mixed and kids. The Hebrew must fit everyone:

- **No second person singular.** Not "נסה שוב", "אתה", "בחר", "הזן". Instead:
  - "אפשר לנסות שוב", "אפשר לבחור…"
  - plural imperative for instructions: "בחרו", "לחצו", "שלחו". Common in Israeli apps and fits everyone.
  - nouns for buttons: "שמירה", "הצטרפות", "שליחה".
- **No "הוא/היא/שלו/שלה" about a player.** Use the name, or rephrase: "התארים" instead of
  "התארים שלו", "מי שמגיע" instead of "השחקן שמגיע".
- **Nouns for people:** prefer plural or neutral forms ("השחקנים", "מי ש…", "חברי הקבוצה").
  Avoid slash forms like "שחקן/ית".
- Jokes and funny lines are rewritten so they fit anyone, not just men.

## English

- American English in `en/`: soccer, field, goalie or goalkeeper, tie, shutout, standings, schedule.
  British differences go in `en-GB/` (football, pitch, draw, clean sheet, defence, neighbourhood).
- Short and friendly, the same tone as the Hebrew. Write English that sounds natural, not a word-for-word
  translation. Jokes and taglines are rewritten so they're funny in English.
- Sentence case for buttons and titles ("Save changes", not "Save Changes").
